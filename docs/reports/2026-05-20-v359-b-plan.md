## 0. TL;DR

POJ continuous 目前走「POJ→TL canonicalize → `tl:` FST lookup」(commit `cf48bbae` Phase 9 引入)。B 把 POJ 升 first-class:**FST key 端**改 mode-aware `poj:`/`tl:`,**syllable inventory** 加 POJ 軸(tagged-single-FST 預設),**candidate roman 顯示**走既有 runtime derive(`phonetics::api::tl_display_to_poj_display`)— **不**改 `dict.bin` schema(只有 C 才動 schema)。TL/TPS/English 維持現狀。

**架構支點**:
- Key 層 mode-aware(`tl:`/`poj:` prefix)
- Syllable inventory 加 POJ tag(`tl:tsiah`/`poj:chiah` 並存,mode-filter)
- Walker / Scorer / SortKey / dict.bin schema 完全不動

**Cost re-estimate**(Codex 校正 #10):**+1800-2500 LOC engine**(原 v2 估 +1200-1400 過樂觀,Codex 抓:syllable inventory 分軸 plumb / 非-ASCII POJ offset map / POJ 縮寫 guard / custom canonical fallback / golden churn / build artifact regen)
