# Rust shared-core artefacts (macOS)

`RustTaigi.xcframework`, `RustTaigi.swift`, and `SwiftBridgeCore.swift` are
regenerated by `engine/scripts/build-macos-xcframework.sh` (`make macos-engine`).

Do not edit manually. The committed copies exist so the SwiftPM package
resolves a stable `binaryTarget` path across a fresh clone.

Single slice: `macos-arm64` (`aarch64-apple-darwin`). Intel is a user-gated
later step.

The xcframework wraps `engine/swift-ffi` (Rust) — the same crate iOS links.
Exported surface is the `mod ffi` bridge block in `engine/swift-ffi/src/lib.rs`;
not restated here, so the two platform READMEs cannot drift from it.

**Drift rule**: `engine/swift-ffi` is shared. After any change to that crate,
regenerate BOTH `ios/RustEngine/` (`make build`) and this directory
(`make macos-engine`).
