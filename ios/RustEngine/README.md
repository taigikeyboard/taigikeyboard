# Rust shared-core artefacts

`RustTaigi.xcframework` and `RustTaigi.swift` are regenerated by
`engine/scripts/build-xcframework.sh` (release) or
`engine/scripts/build-xcframework.sh --dev` (dev / tests with panic-injector).

Do not edit manually. The committed copies exist so Xcode source references
are stable across a fresh clone.

The xcframework wraps `engine/swift-ffi` (Rust) and exposes:

- `process_request_bytes(_:)` — single FFI entry point
- `install_logger_sink(_:)` — registers a Swift `LoggerBackend` adapter
- `panic_for_test()` — T1 injector; only triggers when the dev xcframework is built
