#### Bug Fixes
- **Fix SQLite WAL storage bloat**: Changed journal mode from WAL to DELETE in `SQLiteConnectionManager` — iOS keyboard extension's short lifecycle prevented auto-checkpoint from triggering, causing `.db-wal` files to grow indefinitely (8.25GB). Added one-time migration to checkpoint and clean up existing WAL files for upgrading users
- **NextWord stale suggestions on textDidChange**: Fixed `textDidChange` never clearing NextWord suggestions from UI (state was reset before the display check, making the check always false)
- **NextWord stale suggestions on sentence-end punctuation**: Fixed sentence-end punctuation (。！？.!?) resetting NextWord state but leaving stale suggestions visible in autocomplete bar
