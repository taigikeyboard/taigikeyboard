## v3.4.9

### iOS

#### Refactoring: Eliminate dictionary.db — Binary mmap Migration (48 MB → 12.7 MB, −73%)

Replaced SQLite `dictionary.db` with compact binary mmap files for all read-only dictionary data. SQLite retained only for user-writable databases.

**Before**: `dictionary.db` (44 MB) + `dictionary.trie` (4.1 MB) = 48.1 MB
**After**: `dictionary.trie` (5.2 MB) + `dictionary.bin` (4.4 MB) + `association.bin` (3.1 MB) = 12.7 MB

- **DictionaryBinaryReader**: mmap-based O(1) rowid→record lookup with offset table; 16-bit bitmask replaces 13 boolean SQL columns; `loadUnaligned` for safe unaligned integer decoding
- **AssociationBinaryReader**: mmap-based binary search on sorted key table for NextWord bigram predictions; replaces `word_association` SQLite table; bounds validation on all file-derived offsets
- **Hanzi search merged into dictionary.trie**: Hanzi prefix keys (`hanzi:好`) merged into main trie alongside romanization keys (`tl:`, `poj:`); eliminates separate `hanzi.trie` file and `hanziTrieService`
- **Multi-trie C bridge**: Handle-based API (`trie_create`/`trie_h_lookup`/`trie_h_prefix_search`/`trie_h_close`); legacy global trie API removed
- **TrieService**: Added `deinit` for handle cleanup; `LexiconConstants.TriePrefix.hanzi` constant for unified prefix pattern
- **DictionaryRepository**: Rewritten from SQLite to binary reader; extracted `lookupRowIds()` to eliminate duplicated trie lookup pattern; `EnabledDictionaries` with `sourceBitmask()` and `associationBitmask()`; named bitmask constants (`khiinBit`, `devBit`, `variantBit`)
- **NextWordService**: Dict association path migrated from SQLite to `AssociationBinaryReader`; preserves 2× over-fetch for dedup merging; bitmask construction centralized in `EnabledDictionaries`

#### New Files
- `Lexicon/Database/DictionaryBinaryReader.swift` — binary dictionary mmap reader
- `Lexicon/Database/AssociationBinaryReader.swift` — binary association mmap reader

#### Removed
- `Resources/Dictionaries/dictionary.db` — replaced by `dictionary.bin` + `association.bin`
- `Resources/Dictionaries/hanzi.trie` — merged into `dictionary.trie` with `hanzi:` prefix

### Build Pipeline

- `dictionaryv2/` — build pipeline producing binary format (iOS) alongside SQLite (Android)
  - `10_create_dictionary_bin.py` — generates `dictionary.bin` with `--verify` mode
  - `11_create_association_bin.py` — generates `association.bin` with `--verify` mode
  - `04_create_trie.py` — generates merged `dictionary.trie` with `tl:`, `poj:`, `hanzi:` prefix keys
  - Struct format: `b` (signed) → `B` (unsigned) for all length fields
- **kesi → taigi-converter migration**: Replaced broken kesi dependency with taigi-converter (git submodule) via persistent Node.js subprocess bridge
  - `common/taigi_batch.js` — line-based JSON IPC server (convert, toToneNumber, validate)
  - `common/taigi_bridge.py` — Python wrapper with `convert_tl_to_poj`, `is_valid_romanization`, `normalize_taibun`
  - MOE 教育部造字碼 → Unicode mapping (9 code points) preserved from kesi
  - `parseSyllable` validation replaces `kam_haphuat` — strict TL phonological check
