## v3.5.1

### iOS

#### Refactoring: Input Engine — TPS Module Split

Decompose the 644-line `TPSConverter` monolith into four single-responsibility files under `ios/Sources/TaigiKeyboard/Input/TPS/`:

- `TPSTables.swift` — static lookup data
- `TPSToTL.swift` — TPS → TL conversion
- `TLToTPS.swift` — TL → TPS conversion (including display-text variant)
- `TPSInputAdjuster.swift` — input normalization / palatalization

`TPSConverter.swift` reduced to 60 lines of glue re-exports. Callers (`LexiconService`, `InputNormalizer`, `ActionHandler+Suggestions`) migrated to the new granular APIs. Behaviour unchanged.

#### Refactoring: Input Engine — Composing Submodule + CharacterInputPipeline

- `ComposingManager.swift` moved into its own `Input/Composing/` folder.
- `ComposingDelegate` extracted into a dedicated file, separating the protocol contract from the implementation.
- New `CharacterInputPipeline.swift` encapsulates the per-key input flow previously inlined in `KeyboardViewController+TextInput`.
- `CaseTransformationService.swift` renamed to `CaseTransformer.swift` (filename now matches the type).
- Missing `UIKit` / `Combine` imports added where the reorg exposed them; `docs/engine/composing.md` refreshed to match.
- New `ComposingManagerTests.swift` covering the public surface.

#### Refactoring: Autocomplete — Service Phase Split + View Decoupling

`AutocompleteService.autocomplete(_:)` is now a thin orchestrator that calls four named phases: `classifyInput` → `searchLexicon` → `applyContextBoost` → `buildSuggestions`.

- Pure-logic `AutocompleteInputClassifier` and `AutocompleteContextBooster` enums extracted (same file), named to match the Android `TaigiAutocompleteService` counterparts so a future cross-platform core can absorb them unchanged.
- Compacted 10 unused KeyboardKit learning stubs (protocol-required, no-op for Taigi).
- `CandidateCellHelper` stops reading `SharedSettings.shared`; layout flags (`isTPSLayout` / `orMapsToER`) are now injected, making the helper a pure function family and unit-testable.
- Three duplicate `TLToTPS.convert` call sites deduplicated into one private `tpsFallback`; two commit-suggestion rebuilders merged into `replacingCommitText`; dead `titleFontSize` / `subtitleFontSize` branches removed.
- Layout flags threaded once through `TaigiKeyboardView` → `CandidateView` / `ExpandedCandidateOverlay` / cells so render-hot paths stay singleton-free.
- `SettingsSnapshot` extended with `isTpsOrMappedToER` to keep the per-render snapshot complete.
- Dropped the unused `frequentWords` pipeline (property was threaded through 4 files but never read by any cell).
- Double provider-wiring in `KeyboardViewController+Setup` collapsed into a shared `wireTaigiAutocompleteProviders(from:to:)` helper; the two call paths (initial setup vs. input-mode change) still run through the same code.

New unit tests:

- `AutocompleteInputClassifierTests.swift` — covers tone 1 / 4 exclusion from the numeric-tone rule, hanzi / roman classification.
- `AutocompleteContextBoosterTests.swift` — covers partition ordering, empty-prediction passthrough, roman-first-char fallback when `hanzi` is absent.

**Explicitly out of scope** (deferred):

- Consolidating `CandidateButtonView` and `ExpandedCandidateGridCell` into one shared cell — the two have divergent padding / spacing / cornerRadius that make a naive merge regress the UI.
- Wrapping `isTPSLayout` / `orMapsToER` into a `LayoutContext` struct — current threading is only 4 hops, not yet worth the extra type.
- Extracting `AutocompleteInputClassifier` / `AutocompleteContextBooster` into a shared Swift Package / KMP module — this release only renames them to match Android so a future extraction is mechanical.

### Android

#### Changes: Settings UX

Removed redundant leading icons from three toggle rows on the Tab4 "Input Settings" screen (`outputBothScripts`, `autoCapitalization`, `autoSpace`). Icons duplicated the labels without adding clarity; row label + info button now stand alone.

- Updated `docs/engine/tps.md` and `docs/engine/composing.md` to reflect the new TPS / Composing module layout.
