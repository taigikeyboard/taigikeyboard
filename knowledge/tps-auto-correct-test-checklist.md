# 方音符號自動校正 — Release 前手動測試清單

每次 release 前，佇 iOS 佮 Android 攏愛測過一擺。

---

## Rule 1: 顎化自動校正

拍 ㄧ 或 ㆪ ê 時，頭前 ê 齒音自動改做顎化音。

- [ ] ㄗ + ㄧ → 顯示 ㄐㄧ（搜尋結果 = tsi）
- [ ] ㄘ + ㄧ → 顯示 ㄑㄧ（搜尋結果 = tshi）
- [ ] ㄙ + ㄧ → 顯示 ㄒㄧ（搜尋結果 = si）
- [ ] ㆡ + ㄧ → 顯示 ㆢㄧ（搜尋結果 = ji）
- [ ] ㄗ + ㆪ → 顯示 ㄐㆪ（搜尋結果 = tsinn）
- [ ] ㄘ + ㆪ → 顯示 ㄑㆪ（搜尋結果 = tshinn）
- [ ] ㄙ + ㆪ → 顯示 ㄒㆪ（搜尋結果 = sinn）
- [ ] ㆡ + ㆪ → 顯示 ㆢㆪ（搜尋結果 = jinn）

### 不應觸發

- [ ] ㄙ + ㄚ → 顯示 ㄙㄚ（ㄚ 毋是 i 元音，無顎化）
- [ ] ㄒ + ㄧ → 顯示 ㄒㄧ（已經是顎化音，無變化）
- [ ] ㄍ + ㄧ → 顯示 ㄍㄧ（ㄍ 毋是齒音，無顎化）

---

## Rule 2: 聲母／韻尾自動切換

仝一粒揤鈕，佇音節頭是聲母，佇音節中間自動變韻尾。

### 鼻音韻尾

- [ ] (空) + ㄇ → 顯示 ㄇ（聲母 m）
- [ ] ㄚ + ㄇ → 顯示 ㄚㆬ（韻尾 -m，搜尋 = am）
- [ ] (空) + ㄋ → 顯示 ㄋ（聲母 n）
- [ ] ㄚ + ㄋ → 顯示 ㄚㄣ（韻尾 -n，搜尋 = an）
- [ ] ㄒㄧ + ㄋ → 顯示 ㄒㄧㄣ（搜尋 = sin）
- [ ] (空) + ㄫ → 顯示 ㄫ（聲母 ng）
- [ ] ㄚ + ㄫ → 顯示 ㄚㆭ（韻尾 -ng，搜尋 = ang）
- [ ] ㄧ + ㄫ → 顯示 ㄧㄥ（特殊：ㄧ 後用 ㄥ，搜尋 = ing）

### 入聲韻尾

- [ ] (空) + ㄅ → 顯示 ㄅ（聲母 p）
- [ ] ㄍㄚ + ㄅ → 顯示 ㄍㄚㆴ（韻尾 -p，搜尋 = kap）
- [ ] (空) + ㄉ → 顯示 ㄉ（聲母 t）
- [ ] ㄍㄚ + ㄉ → 顯示 ㄍㄚㆵ（韻尾 -t，搜尋 = kat）
- [ ] (空) + ㄍ → 顯示 ㄍ（聲母 k）
- [ ] ㄍㄚ + ㄍ → 顯示 ㄍㄚㆻ（韻尾 -k，搜尋 = kak）
- [ ] (空) + ㄏ → 顯示 ㄏ（聲母 h）
- [ ] ㄍㄚ + ㄏ → 顯示 ㄍㄚㆷ（韻尾 -h，搜尋 = kah）

### 音節邊界（新音節 → 維持聲母）

- [ ] ˋ + ㄇ → 顯示 ...ˋㄇ（聲調後是新音節，維持聲母）
- [ ] ˋ + ㄅ → 顯示 ...ˋㄅ（聲調後是新音節，維持聲母）
- [ ] ㆴ + ㄅ → 顯示 ...ㆴㄅ（入聲韻尾後是新音節，維持聲母）
- [ ] 空白 + ㄋ → 顯示 ...ㄋ（空白後是新音節，維持聲母）

---

## Rule 2b: 獨立鼻音聲調校正（ㄇ/ㄫ + 聲調 → ㆬ/ㆭ）

音節頭拍 ㄇ 或 ㄫ，接聲調記號 ê 時，自動改做獨立鼻音形式。

- [ ] (空) + ㄇ + ˫ → 顯示 ㆬ˫（搜尋 = m7）
- [ ] (空) + ㄇ + ˋ → 顯示 ㆬˋ（搜尋 = m2）
- [ ] (空) + ㄫ + ˊ → 顯示 ㆭˊ（搜尋 = ng5）
- [ ] (空) + ㄫ + ˋ → 顯示 ㆭˋ（���尋 = ng2）

### 不應觸發

- [ ] ㄚ + ㄇ(→ㆬ) + ˫ → 顯示 ㄚㆬ˫（ㆬ 已是韻尾，Rule 2 處理，無影響）
- [ ] (空) + ㄇ + ㄚ → 顯示 ㄇㄚ���ㄚ 毋是聲調記號，ㄇ 維持聲母）

---

## Rule 3: 鼻化韻自動校正（ㆮ→ㆯ）

ㄧ 後拍 ㆮ（ainn）自動改做 ㆯ（aunn），因為台語無「iainn」這个韻母。

- [ ] ㄧ + ㆮ → 顯示 ㄧㆯ（搜尋 = iaunn）
- [ ] ㄚ + ㆮ → 顯示 ㄚㆮ（無變化，ainn 是合法韻母）

---

## Rule 2 補充: 鼻音韻尾後接新音節

鼻音韻尾（ㆬ/ㄣ/ㆭ/ㄥ）後接聲母，應該開始新音節，毋是繼續轉韻尾。

- [ ] ㄒㄧ + ㄇ(→ㆬ) + ㄇ → 顯示 ㄒㄧㆬㄇ（第二个 ㄇ 是新音節聲母，毋是 ㆬ）
- [ ] ㄚ + ㄋ(→ㄣ) + ㄋ → 顯示 ㄚㄣㄋ（第二个 ㄋ 是聲母）
- [ ] ㄚ + ㄫ(→ㆭ) + ㄍ → 顯示 ㄚㆭㄍ（ㄍ 是新音節聲母，毋是 ㆻ）
- [ ] ㄧ + ㄫ(→ㄥ) + ㄍ → 顯示 ㄧㄥㄍ（ㄍ 是新音節聲母）
- [ ] ㄒㄧ + ㄇ(→ㆬ) + ㄅ → 顯示 ㄒㄧㆬㄅ（ㄅ 是新音節聲母，毋是 ㆴ）

### 多音節免聲調搜尋

- [ ] ㄒㄧ + ㄇ(→ㆬ) + ㄇ + ㄨ + ㄚ → toTL "sim mua" → 候選有結果
- [ ] ㄍㄚ + ㄫ(→ㆭ) + ㄍ + ㄚ + ㄨ → toTL "kang kau" → 候選有結果

## 實詞測試

用實際詞彙確認自動校正 + 搜尋結果正確。

- [ ] 錢 tsînn：拍 ㄗ + ㆪ + ˊ → 顯示 ㄐㆪˊ → 候選有「錢」
- [ ] 心 sim：拍 ㄙ + ㄧ + ㄇ → 顯示 ㄒㄧㆬ → 候選有「心」
- [ ] 因 in：拍 ㄧ + ㄋ → 顯示 ㄧㄣ → 候選有「因」
- [ ] 港 káng：拍 ㄍ + ㄚ + ㄫ + ˊ → 顯示 ㄍㄚㆭˊ → 候選有「港」
- [ ] 永 íng：拍 ㄧ + ㄫ + ˊ → 顯示 ㄧㄥˊ → 候選有「永」
- [ ] 角 kak：拍 ㄍ + ㄚ + ㄍ → 顯示 ㄍㄚㆻ → 候選有「角」
- [ ] 答 tap：拍 ㄉ + ㄚ + ㄅ → 顯示 ㄉㄚㆴ → 候選有「答」
- [ ] 食 tsia̍h：拍 ㄗ + ㄧ + ㄚ + ㄏ + ˙ → 顯示 ㄐㄧㄚㆷ˙ → 候選有「食」
- [ ] 嘔 iáunn：拍 ㄧ + ㆮ + ˊ → 顯示 ㄧㆯˊ → 候選有「嘔」
