# KeyboardKit 10 升級指南

> **類型**: 框架
> **關鍵字**: `KeyboardKit`, `KK10`, `Migration`
> **相關**: flow.md

---

## 重點摘要

- KeyboardKit 9.x → 10.x 的升級記錄
- 使用免費版，不購買 Pro
- 主要變更：Services 架構、KeyboardCase.auto 移除

---

## 系統需求

| 平台 | 最低版本 |
|------|----------|
| iOS | 16 |
| macOS | 13 |

---

## 重大架構變更

### SDK 合併

- KeyboardKit + KeyboardKit Pro → 單一 SDK
- `import KeyboardKitPro` → `import KeyboardKit`
- 閉源模式

### 專案決定

使用免費版，影響：
- Emoji Keyboard：使用 `ISEmojiView`
- Themes：使用自訂 `View+Theme.swift`
- Autocomplete：使用自訂 `AutocompleteService`

---

## Breaking Changes

### 移除的 API

| 移除 | 替代方案 |
|------|----------|
| `Keyboard.KeyboardCase.auto` | `isUppercasedOrCapslocked` |
| `Keyboard.KeyboardType.webSearch` | `.alphabetic` |
| `services.layoutService` | `KeyboardView(layout:)` |
| `StandardLayoutService` | 自訂類別 |
| `Autocomplete.ServiceResult` | `Autocomplete.Result` |

### 命名變更

| v9 | v10 |
|----|-----|
| `spaceDragGestureHandler` | `spacebarDragGestureHandler` |
| `spaceLongPressBehavior` | `spacebarLongPressBehavior` |
| `setIsLiquidGlassEnabled()` | `isLiquidGlassEnabled =` |

---

## Keyboard.Services 結構（v10）

| 屬性 | 說明 |
|------|------|
| `actionHandler` | 動作處理器 |
| `autocompleteService` | 自動完成服務 |
| `dictationService` | 聽寫服務 |
| `feedbackService` | 回饋服務 |
| `keyboardBehavior` | 鍵盤行為 |
| `repeatGestureTimer` | 重複手勢計時器 |
| `spacebarDragGestureHandler` | 空白鍵拖拽 |

已移除：`layoutService`, `styleService`, `calloutService`

## API 替代方案

### KeyboardCase.auto

```swift
// ❌ v9
keyboardContext.keyboardCase == .auto

// ✅ v10
keyboardContext.keyboardCase.isUppercasedOrCapslocked
```

### LayoutService

```swift
// ❌ v9
services.layoutService = CustomLayoutService()

// ✅ v10
let layout = KeyboardLayout.standard(for: keyboardContext)
KeyboardView(layout: layout, services: services)
```

### StyleService

```swift
// ❌ v9
services.styleService = CustomStyleService()

// ✅ v10
// 使用 buttonContent 自訂
KeyboardView(
    layout: layout,
    services: services,
    buttonContent: { params in TaigiButtonContent(...) }
)
```

### CalloutService

```swift
// ❌ v9
class TaigiCalloutService: CalloutService { ... }

// ✅ v10
KeyboardView(...)
    .keyboardCalloutActions(customActionsBuilder)
```

## Swift 6 相容性

```swift
// ⚠️ 需加入 @unknown default
switch keyboardCase {
case .uppercased, .capsLocked:
    char.uppercased()
case .lowercased:
    char.lowercased()
@unknown default:
    char.lowercased()
}
```
